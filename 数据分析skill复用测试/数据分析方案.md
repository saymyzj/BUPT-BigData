# 数据分析方案

## 1. 分析目标

本阶段基于已清洗的医疗健康与生物医药上市公司数据，完成可复用的数据分析交付。分析目标包括：

1. 总结 2024 年公司股价、成交量、收益率波动和最新研发投入的分布特征。
2. 按月跟踪 2024 年市场表现趋势，识别近期变化方向。
3. 分析研发投入、价格、成交量、收益率和波动率之间的线性相关关系。
4. 基于公司级特征形成风险或关注分组，辅助后续可视化和业务解释。
5. 识别日度收益率和成交量的异常候选事件。
6. 对行业分组和官方字段文本做关键词关注分析，不虚构社交媒体情绪。
7. 输出结构化 CSV 和 Markdown 报告，方便课程展示、后续建模或可视化复用。

## 2. 输入数据清单

| 输入文件 | 数据内容 | 分析用途 |
|---|---|---|
| `data/processed/rd_annual_clean.csv` | 43 家公司多年 SEC 年度研发费用记录，共 527 行 | 年度研发投入描述统计、研发趋势和最新研发投入引用 |
| `data/processed/stock_daily_clean.csv` | 43 家公司 2024 年日行情记录，共 10836 行 | 日度价格、收益率、成交量趋势和异常检测 |
| `data/processed/company_2024_features.csv` | 43 家公司 2024 年特征宽表 | 公司级描述统计、相关性分析、风险分组 |
| `data/processed/data_dictionary.csv` | 清洗阶段字段字典 | 字段含义、单位和缺失处理依据 |
| `data/processed/quality_summary.json` | 清洗质量摘要 | 行数、缺失值和质量说明校验 |

## 3. 输入数据检查

| 检查项 | 结论 |
|---|---|
| 数据字典 | 已包含表名、字段名、类型、单位、缺失值策略、来源字段和字段说明 |
| 时间字段 | `stock_daily_clean.trade_date` 为日度日期，`trade_month` 为月度字段，`rd_annual_clean.fiscal_year` 为年度字段 |
| 数值字段 | 价格、成交量、收益率、收益率波动、研发费用等字段可用于统计、相关性和分组 |
| 类别字段 | `ticker`、`company_name`、`industry_group` 可作为公司和行业分组变量 |
| 缺失值 | 日收益率首个交易日为空属于结构性空值；少量最新研发字段为空，不做主观插补 |
| 分析粒度 | 日行情为公司 × 交易日；公司特征为公司 × 2024 年；研发费用为公司 × 财年 |

## 4. 分析方法设计

| 分析类型 | 方法 | 输出 |
|---|---|---|
| 描述性统计 | 对公司级、日度和年度数值字段计算观测数、均值、最小值、最大值、总和、最新值 | `data/analysis/descriptive_statistics.csv` |
| 时间序列趋势 | 按月汇总平均收盘价、平均复权收盘价、总成交量、平均收益率、研发费用年度总额，计算最新值、上期值、变化量、变化率和近 4 期均值 | `data/analysis/time_series_summary.csv` |
| 相关性分析 | 对公司级特征宽表中的数值字段计算 Pearson 相关系数，并标注强度与方向 | `data/analysis/correlation_matrix.csv` |
| 聚类/风险分组 | 使用标准化后的研发投入、收益率波动、平均收益率、成交量和年末复权价构造综合风险得分，按三分位划分低、中、高关注组 | `data/analysis/cluster_results.csv` |
| 异常检测 | 按公司序列计算日收益率和成交量 z-score，`abs(z_score) >= 2` 标记为异常候选 | `data/analysis/anomaly_detection_results.csv` |
| 关键词关注分析 | 基于行业分组与公司字段统计业务关键词出现次数和覆盖公司数，不作为社交媒体情绪结论 | `data/analysis/keyword_sentiment_analysis.csv` |
| 分析数据字典 | 汇总所有分析输出字段含义、类型和单位 | `data/analysis/analysis_data_dictionary.csv` |
| 机器可读摘要 | 汇总核心指标、文件行数和关键结论 | `data/analysis/analysis_summary.json` |

## 5. 输出文件设计

| 输出文件 | 说明 |
|---|---|
| `data/analysis/descriptive_statistics.csv` | 各数据表和行业分组的核心数值指标统计 |
| `data/analysis/time_series_summary.csv` | 月度、年度序列的趋势摘要 |
| `data/analysis/correlation_matrix.csv` | 公司级数值变量两两相关性 |
| `data/analysis/cluster_results.csv` | 公司风险关注分组和特征值 |
| `data/analysis/anomaly_detection_results.csv` | 日度收益率和成交量异常候选 |
| `data/analysis/keyword_sentiment_analysis.csv` | 官方字段关键词关注统计 |
| `data/analysis/analysis_data_dictionary.csv` | 分析结果字段字典 |
| `data/analysis/analysis_summary.json` | 分析摘要和输出行数 |

## 6. 脚本设计

脚本路径为 `src/analysis/analyze_cleaned_data.py`。主要函数包括：

| 函数 | 职责 |
|---|---|
| `read_csv` / `write_csv` | 统一读取和写出 CSV |
| `to_float` | 将字符串字段转换为数值 |
| `generate_descriptive_statistics` | 生成描述统计 |
| `generate_time_series_summary` | 生成时间序列趋势摘要 |
| `generate_correlation_matrix` | 生成相关性矩阵 |
| `generate_cluster_results` | 生成公司风险分组 |
| `generate_anomaly_results` | 生成异常检测结果 |
| `generate_keyword_sentiment_analysis` | 生成关键词关注分析 |
| `build_analysis_dictionary_rows` | 生成分析输出字段说明 |
| `build_summary` | 汇总核心结论和输出行数 |
| `run_analysis` | 串联完整分析流程 |

## 7. 整体应用方向

1. 构建医疗健康上市公司研发投入与市场表现监测看板，支持行业对比、公司筛选和趋势展示。
2. 构建投资研究或课程实验中的早期预警候选模块，对异常收益率、异常成交量和高波动公司进行提示。
3. 支持监管、产业研究或创新评价场景，对研发投入强度、市场波动和行业结构进行持续跟踪。

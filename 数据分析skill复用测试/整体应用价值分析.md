# 整体应用价值分析

## 1. 应用方向

| 应用方向 | 内容 | 落地方式 |
|---|---|---|
| 医疗健康上市公司研发与市场表现监测看板 | 将研发投入、股价、成交量、收益率和波动率按公司、行业、月份展示 | 使用 `data/analysis/` 中的 CSV 结果接入 BI 或前端可视化 |
| 早期预警候选系统 | 对异常收益率、异常成交量和高关注公司进行提示 | 使用 `anomaly_detection_results.csv` 和 `cluster_results.csv` 建立复核清单 |
| 产业创新评价辅助工具 | 比较公司研发投入与市场表现的共变特征 | 使用 `correlation_matrix.csv` 和描述统计结果形成研究报告 |
| 课程实验复用模板 | 复用从数据采集、清洗、分析到报告的完整流程 | 保留方案、脚本、数据字典、报告和验证命令 |

## 2. 技术可行性

| 维度 | 结论 |
|---|---|
| 数据 | 已有清洗后的 CSV、字段字典和质量摘要，输入结构明确 |
| 脚本 | `src/analysis/analyze_cleaned_data.py` 使用 Python 标准库，可在轻量环境复跑 |
| 算法 | 描述统计、Pearson 相关、z-score 异常检测和标准化风险评分均适合课程实验和原型验证 |
| 部署 | 输出为 CSV 和 JSON，可直接接入可视化、报告生成或后续建模模块 |
| 可维护性 | 输出字段顺序固定，并提供 `analysis_data_dictionary.csv` 说明字段含义 |

## 3. 成本效益

| 成本或收益 | 分析 |
|---|---|
| 数据成本 | 数据来自公开接口和公开披露，适合低成本实验与研究 |
| 开发成本 | 标准库脚本降低依赖安装成本，后续可按模块扩展 |
| 运行成本 | 当前数据规模较小，单机即可快速运行 |
| 收益 | 可形成持续监测、异常提示、行业对比和课程展示成果 |
| 风险 | 若用于真实投研或监管场景，需要补充事件、新闻、财务和人工复核流程 |

## 4. 市场需求

| 场景 | 需求 |
|---|---|
| 学校 | 支持大数据课程实验、技能复用展示和团队分工交付 |
| 企业 | 支持竞品研发投入和市场表现监测 |
| 医院或科研机构 | 辅助观察医疗健康企业创新活跃度和行业动态 |
| 投研机构 | 作为轻量数据底座，辅助生成候选观察清单 |
| 监管或产业园区 | 支持行业结构、创新投入和市场波动的持续观察 |

## 5. 数据可用性

| 维度 | 结论 |
|---|---|
| 数据规模 | 覆盖 43 家公司、10836 行日行情、527 行年度研发费用，足够支撑课程级分析 |
| 数据质量 | 清洗质量摘要显示关键字段整体完整，日收益率首日空值属于结构性空值 |
| 时间粒度 | 日行情可聚合为月度趋势，研发费用以财年为粒度 |
| 字段完整性 | 价格、成交量、收益率、波动率、研发费用和行业分组字段较完整 |
| 局限 | 缺少新闻、临床试验、宏观指标和公司事件字段，异常原因解释仍需外部材料 |

## 6. 项目价值

本项目的核心价值在于将公开市场数据和公开研发披露整理为可复用的结构化分析成果。它既能服务课程作业中的完整流程展示，也能作为后续可视化、报告自动化和轻量预警系统的输入。

在业务层面，项目可以帮助用户快速定位高波动、高成交量或高研发投入公司；在研究层面，可以支持行业间和公司间的探索性比较；在工程层面，脚本与数据字典让分析过程具备可重复性和可审计性。

## 7. 后续扩展建议

1. 接入新闻公告、临床试验进展、FDA 审批和财报事件，提高异常解释能力。
2. 增加滚动窗口波动率、最大回撤、研发费用增长率等更细指标。
3. 将风险分组从规则评分升级为可解释的聚类模型，并保留人工复核机制。
4. 建立定期更新流程，按月或按周自动刷新分析结果。

# 《呼吸道传染病监测与早期预警分析系统》数据分析方案

## 一、分析目标

本阶段基于 `data/processed/` 中的清洗结果，围绕呼吸道传染病监测和早期预警需求，完成描述性统计、时间序列趋势分析、相关性分析、聚类风险分组、异常检测和公共卫生关注关键词分析。分析结果用于支撑成员 B 的报告撰写，并为成员 C 的可视化 Dashboard 提供结构化结果文件。

分析目标包括：

1. 总结重点呼吸道病种和主要病原体的总体分布特征。
2. 观察月度病例数、周度阳性率、流感指标和暴发疫情数的变化趋势。
3. 分析气象因素与呼吸道监测指标之间的相关关系。
4. 对城市周度记录进行风险分组，形成低风险、中风险和高风险类别。
5. 识别异常升高周，为早期预警指标设计提供候选事件。
6. 基于官方通报标题、病种名、病原体名和指标名提取关注关键词。

## 二、输入数据

| 输入文件 | 数据内容 | 用途 |
|---|---|---|
| `data/processed/chinacdc_monthly_clean.csv` | 全国法定传染病月报清洗表 | 重点病种月度发病趋势分析 |
| `data/processed/respiratory_weekly_clean.csv` | 急性呼吸道哨点周报清洗表 | 病原体阳性率趋势和异常分析 |
| `data/processed/influenza_weekly_clean.csv` | 流感监测周报清洗表 | ILI%、暴发疫情数、优势毒株分析 |
| `data/processed/province_weekly_features.csv` | 省份周度特征宽表 | 气象相关性分析和风险聚类 |

## 三、分析方法设计

### 1. 描述性统计

| 分析对象 | 指标 |
|---|---|
| 重点病种月度病例数 | 观测期数、均值、最小值、最大值、总数、最新值 |
| 急性呼吸道病原体阳性率 | 观测周数、均值、最小值、最大值、最新值 |
| 流感监测指标 | ILI%、暴发疫情数、指标均值、峰值和最新值 |
| 周度气象指标 | 各地区气温、湿度、降水和风速的均值、峰值 |

### 2. 时间序列趋势分析

对每个重点序列计算：

- 起始时间和结束时间
- 观测期数
- 最新值
- 上一期值
- 环比变化量
- 环比变化率
- 最近 4 期均值
- 趋势方向：上升、下降或持平

### 3. 相关性分析

以 `province_weekly_features.csv` 为基础，先将城市周度数据压缩为全国周度均值，避免同一周健康监测指标被不同城市重复计数。随后计算气象指标与健康监测指标之间的 Pearson 相关系数。

| 气象变量 | 健康监测变量 |
|---|---|
| `avg_temperature` | 呼吸道病原体阳性率 |
| `avg_humidity` | 流感 ILI% |
| `precipitation_total` | 流感暴发疫情数 |
| `wind_speed` | 新冠、流感、RSV 等病原体阳性率 |

相关性强度划分：

| 相关系数绝对值 | 解释 |
|---:|---|
| ≥ 0.7 | 强相关 |
| 0.4-0.7 | 中等相关 |
| 0.2-0.4 | 弱相关 |
| < 0.2 | 相关较弱 |

### 4. 聚类风险分组

对城市周度记录使用 K-Means 聚类，分为 3 类：

| 类别 | 含义 |
|---|---|
| 低风险 | 健康监测指标和风险得分较低 |
| 中风险 | 指标处于中间水平 |
| 高风险 | 病原体阳性率、ILI% 或暴发疫情数相对较高 |

使用特征包括：

- 周平均气温
- 周平均湿度
- 周累计降水量
- 周平均风速
- 流感 ILI%
- 流感暴发疫情数
- 新冠、流感、RSV、肺炎支原体等病原体阳性率

### 5. 异常检测

采用 Z-score 方法识别异常值：

```text
z_score = (当前值 - 序列均值) / 标准差
```

判断规则：

| 条件 | 结果 |
|---|---|
| `z_score >= 2` | 异常高值 |
| `z_score <= -2` | 异常低值 |
| `abs(z_score) < 2` | 正常波动 |

### 6. 关注关键词分析

由于本项目未采集微博、新闻评论等真实社交舆情数据，因此本阶段采用“官方通报文本关键词分析”作为舆情关键词分析的替代方案。分析对象包括报告标题、病种名称、病原体名称、指标名称和优势毒株字段。

| 分析项 | 说明 |
|---|---|
| 关键词频次 | 统计流感、新冠、肺结核、RSV、暴发、疫情等关键词出现次数 |
| 文档覆盖数 | 统计包含该关键词的记录数 |
| 关注标签 | 将风险词标记为风险关注，其他关键词标记为常规监测关注 |
| 适用范围 | 反映官方通报中的公共卫生关注重点，不代表社交媒体主观情绪 |

## 五、脚本设计

分析脚本为：

```text
src/analysis/analyze_cleaned_data.py
```

运行命令为：

```bash
python src/analysis/analyze_cleaned_data.py
```

脚本仅使用 Python 标准库，不依赖 pandas、scikit-learn 等第三方分析库。聚类算法使用标准库实现的简单 K-Means，相关性分析使用 Pearson 相关系数，异常检测使用 Z-score。

## 六、整体应用方向

本阶段分析结果可支撑以下应用方向：

1. 呼吸道传染病早期预警：通过异常检测识别病例数、阳性率和 ILI% 的异常升高周。
2. 省份或城市周度风险分级：通过聚类结果划分低、中、高风险记录。
3. 气象驱动风险提示：分析气温、湿度、降水与呼吸道病原体阳性率的关系。
4. 重点病原体趋势监测：持续跟踪流感病毒、新冠病毒、RSV、肺炎支原体等指标。

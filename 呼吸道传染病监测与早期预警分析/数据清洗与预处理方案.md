# 《呼吸道传染病监测与早期预警分析系统》数据清洗与预处理方案

## 一、项目主题

本项目题目为《呼吸道传染病监测与早期预警分析系统》。在数据采集阶段已经形成法定传染病月报、急性呼吸道传染病哨点周报、流感监测周报和日度气象辅助数据。数据清洗与预处理阶段的目标，是将采集中间表转换为字段规范、时间粒度统一、可追溯、可直接用于分析和可视化的标准数据集。

清洗与预处理目标包括：

1. 对采集中间表进行字段空白清理、缺失值标准化、日期格式统一和数值类型转换。
2. 对病种名称、病原体名称和地区名称进行标准化，减少同义写法造成的统计偏差。
3. 对日度气象数据按周度和月度聚合，使其可以分别与疾控周报和月报对齐。
4. 构建省份周度特征表，为趋势分析、相关性分析、聚类分析和早期预警分析提供统一输入。
5. 生成数据字典和质量摘要，保证清洗过程可复现、清洗结果可审核。

## 二、清洗原则

本阶段遵循以下原则：

1. 可追溯性：清洗后数据保留 `source_url`、`raw_file`、`crawl_time` 等来源字段，便于回溯原始页面或缓存文件。
2. 最小改动：不随意删除有效记录，不对缺失指标进行主观填补，只做必要的格式标准化。
3. 粒度统一：周报数据统一生成 `year_week`、`week_start`、`week_end`，月报数据统一生成 `period_month`。
4. 口径清晰：区分原始采集字段、清洗标准字段和后续分析派生字段。
5. 可维护性：清洗脚本按数据源拆分函数，保留详细注释和质量摘要，便于后续扩展。

## 四、清洗规则设计

### 1. 通用字段清洗

| 清洗项 | 处理方式 |
|---|---|
| 文本空白 | 去除字段前后空格、换行和连续空白 |
| 缺失值 | 将 `-`、`--`、`—`、`NA`、`N/A`、`null`、`None`、`nan` 统一为空值 |
| 日期字段 | 统一转换为 `YYYY-MM-DD` |
| 数值字段 | 去除逗号、百分号和单位符号，转换为可分析数值 |
| 重复记录 | 按业务主键去重，不按来源缓存路径去重 |
| 字段顺序 | 输出时固定字段顺序，保证后续脚本稳定读取 |

### 2. 病种和病原体标准化

| 类型 | 标准化对象 | 说明 |
|---|---|---|
| 病种 | 新型冠状病毒感染、流行性感冒、肺结核、百日咳、麻疹、猩红热、流行性腮腺炎 | 用于标记呼吸道重点病种 |
| 病原体 | 新型冠状病毒、流感病毒、呼吸道合胞病毒、肺炎支原体、腺病毒、人偏肺病毒、副流感病毒等 | 用于构建周度病原体阳性率特征 |
| 地区 | 全国、南方省份、北方省份、省份名称、城市名称 | 移除多余空格，保持统计口径一致 |

### 3. 时间粒度对齐

| 数据类型 | 原始粒度 | 预处理方式 | 输出字段 |
|---|---|---|---|
| 法定传染病月报 | 月度 | 生成统一年月字段 | `period_month` |
| 急性呼吸道周报 | 周度 | 生成 ISO 周标识和周起止日期 | `year_week`、`week_start`、`week_end` |
| 流感周报 | 周度 | 生成 ISO 周标识和周起止日期 | `year_week`、`week_start`、`week_end` |
| 日度气象 | 日度 | 聚合为周度和月度 | `weather_weekly.csv`、`weather_monthly.csv` |

## 五、输出表设计

### 1. 法定传染病月报清洗表：`chinacdc_monthly_clean`

| 字段 | 含义 |
|---|---|
| `period_month` | 报告年月，格式为 `YYYY-MM` |
| `region` | 地区，本批次为全国 |
| `disease_name` | 标准化后的病种名称 |
| `disease_category` | 法定传染病类别或合计类别 |
| `is_respiratory_focus` | 是否为呼吸道重点病种 |
| `is_total_row` | 是否为总计或合计行 |
| `cases` | 发病数 |
| `deaths` | 死亡数 |

### 2. 急性呼吸道哨点周报清洗表：`respiratory_weekly_clean`

| 字段 | 含义 |
|---|---|
| `year_week` | ISO 周标识 |
| `region_group` | 全国、南方省份、北方省份等 |
| `surveillance_scene` | 门急诊流感样病例或住院严重急性呼吸道感染病例 |
| `metric_type` | 指标类型 |
| `pathogen_name` | 标准化后的病原体名称 |
| `positive_rate` | 病原体阳性率 |
| `week_over_week_change` | 环比变化 |
| `ranked_pathogen` | 排名表中的主要病原体 |

### 3. 流感监测周报清洗表：`influenza_weekly_clean`

| 字段 | 含义 |
|---|---|
| `year_week` | ISO 周标识 |
| `issue_no` | 周报期号 |
| `region_group` | 全国、南方省份或北方省份 |
| `metric_type` | 指标类型 |
| `metric_name` | 指标名称 |
| `metric_value` | 普通数值指标 |
| `metric_percent` | 百分比指标 |
| `dominant_subtype` | 优势流感亚型 |
| `outbreak_count` | 流感样病例暴发疫情数 |
| `indicator_value` | 统一指标值，优先取百分比，其次取数值或暴发疫情数 |

### 4. 气象清洗与聚合表

| 输出表 | 粒度 | 主要字段 |
|---|---|---|
| `weather_daily_clean.csv` | 城市-日 | 日期、城市、经纬度、平均气温、最高气温、最低气温、湿度、降水、风速 |
| `weather_weekly.csv` | 城市-周 | 周起止日期、周平均气温、周平均湿度、周累计降水量、平均风速 |
| `weather_monthly.csv` | 城市-月 | 月平均气温、月平均湿度、月累计降水量、平均风速 |

### 5. 省份周度特征表：`province_weekly_features`

该表是后续分析和可视化的核心宽表。表中每一行对应一个城市在某一周的气象特征，并合并同一周的全国呼吸道病原体阳性率和流感监测指标。

| 字段类型 | 示例字段 | 用途 |
|---|---|---|
| 地区时间字段 | `region`、`city`、`year_week`、`week_start`、`week_end` | 可视化筛选和时间序列分析 |
| 气象字段 | `avg_temperature`、`avg_humidity`、`precipitation_total`、`wind_speed` | 气象相关性分析 |
| 呼吸道监测字段 | `resp_outpatient_ili_influenza_positive_rate`、`resp_hospital_sari_covid_positive_rate` | 病原体趋势和预警指标 |
| 流感监测字段 | `influenza_ili_percent_north`、`influenza_ili_percent_south`、`influenza_outbreak_count` | 流感趋势和南北方对比 |

### 6. 数据字典文件：`data_dictionary.csv`

该文件用于说明清洗产物中的关键字段含义，便于报告撰写、人工审核和小组成员之间交接。

| 字段 | 含义 |
|---|---|
| `table_name` | 字段所属的清洗后数据表文件名 |
| `field_name` | 字段名称 |
| `data_type` | 字段数据类型，如 string、integer、float、date、datetime |
| `unit` | 字段单位，如例、人、%、摄氏度、毫米、米/秒；无单位时为 `-` |
| `missing_value_strategy` | 缺失值处理方式或字段不适用时的保留策略 |
| `source_field` | 来源字段或派生来源，例如 `report_year + report_week` |
| `description` | 字段含义、统计口径或使用说明 |

### 7. 质量摘要文件：`quality_summary.json`

该文件用于记录每张表的清洗质量检查结果，便于验证清洗结果是否可信、规范、合理。

| 字段 | 含义 |
|---|---|
| `input_rows` | 输入表记录数 |
| `output_rows` | 输出表记录数 |
| `duplicates_dropped` | 清洗过程中删除的重复记录数 |
| `missing_cells_by_field` | 各字段空值数量统计，键为字段名，值为空值数量 |
| `feature_columns` | 特征表字段数量，仅用于 `province_weekly_features` |
| `generated_at` | 本次清洗运行时间 |
| `output_dir` | 清洗结果输出目录 |

## 六、质量控制方案

| 质检项 | 检查方式 | 预期结果 |
|---|---|---|
| 行数检查 | 对比输入表与输出表记录数 | 无异常丢失 |
| 重复记录检查 | 按业务主键去重并统计删除数量 | 重复数量可解释 |
| 缺失值检查 | 输出各字段空值数量 | 明确缺失字段是否属于不适用字段 |
| 时间字段检查 | 检查年份、月份、周次、起止日期 | 时间字段格式统一 |
| 数值字段检查 | 检查病例数、阳性率、气象指标是否可解析 | 数值字段可直接统计 |
| 派生表检查 | 检查周度、月度聚合记录数和字段数 | 可供分析和可视化使用 |

## 七、脚本设计与代码规范

清洗脚本为 `src/cleaning/preprocess_data.py`，采用 Python 标准库实现，不额外引入第三方依赖。脚本结构如下：

| 模块 | 作用 |
|---|---|
| 通用工具函数 | 文本清理、数值解析、日期解析、CSV 读写、去重、缺失统计 |
| 单表清洗函数 | 分别处理月报、呼吸道周报、流感周报和气象日表 |
| 聚合函数 | 将气象日表聚合为周表和月表 |
| 特征构建函数 | 合并周度气象特征和全国健康监测指标 |
| 质量输出函数 | 生成数据字典、质量摘要和运行日志 |

为满足代码规范性要求，脚本包含模块说明、函数级 docstring、关键步骤中文注释，并将主流程按阶段拆分，便于小组成员阅读、复用和维护。

## 九、后续分析方向

1. 基于 `chinacdc_monthly_clean.csv` 分析重点呼吸道病种月度趋势和季节性。
2. 基于 `respiratory_weekly_clean.csv` 分析主要病原体阳性率变化和周度异常波动。
3. 基于 `influenza_weekly_clean.csv` 分析 ILI%、优势毒株和暴发疫情数的变化。
4. 基于 `province_weekly_features.csv` 分析气象因素与呼吸道监测指标之间的相关关系。
5. 将 `province_weekly_features.csv` 作为成员 C 可视化 Dashboard 的主要输入数据。

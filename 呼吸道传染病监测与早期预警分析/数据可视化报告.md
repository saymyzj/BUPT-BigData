# 呼吸道传染病监测与早期预警 Dashboard 可视化报告

## 1. 页面概况

成员 C 已完成 `呼吸道传染病监测与早期预警分析` 的交互式 Dashboard。页面位于 `src/dashboard/dashboard.html`，读取 `data/dashboard-data.js` 中的结构化数据。前端数据由 `src/dashboard/prepare_dashboard_data.py` 从成员 B 输出的清洗数据和分析结果中生成。

Dashboard 覆盖 `2024-W01` 至 `2026-W20`，包含 11 类病原体、31 个省市、3844 条城市周度风险记录、83 个异常检测候选点。页面用于课堂展示呼吸道传染病多源监测、风险分级和早期预警原型。

需要说明的是，`respiratory_weekly_clean.csv` 中的急性呼吸道病原体阳性率记录主要从 2025 年开始；2024 年主要通过流感周报中的 ILI%、流感实验室阳性率、流感分型比例、流感样病例暴发数，以及城市周度风险记录进行展示。

## 3. 图表类型与指标

| 图表 | 类型 | 指标说明 |
|---|---|---|
| 周度趋势 | 折线图 | 病原体阳性率、ILI%、流感样病例暴发数 |
| 最新病原体构成 | 环图 | 最新周不同病原体平均阳性率或流感分型比例 |
| 监测场景对比 | 柱状图 | 门急诊与住院场景下的阳性率对比，或南北方 ILI% 对比 |
| 气象与风险散点 | 散点图 | 平均气温、平均湿度、风险得分和风险等级 |
| 省市风险分布图 | 类地图网格 | 各省市平均风险得分和高风险周记录 |
| 强相关指标列表 | 排名条 | 气象与健康监测指标 Pearson 相关系数 |
| 异常检测表 | 表格 | z-score 异常点和预警候选 |

## 4. 交互功能

- 支持按年份、病原体、监测场景、省市筛选。
- 支持选择周范围。
- 支持切换趋势指标。
- 支持趋势图缩放。
- 支持图表悬停查看详细信息。
- 支持筛选重置。
- KPI、趋势图、柱状图、散点图、省市风险分布和异常表会随筛选条件同步更新。

## 5. 可视化解释

折线图用于观察时间序列变化；环图用于展示最新周优势病原体构成；柱状图用于比较不同监测场景或南北方区域口径；散点图用于观察气象条件和风险得分之间的关系；省市分布图用于快速定位风险得分较高地区；异常表用于列出需要进一步人工复核的预警候选。

相关性、聚类风险分级和异常检测均为探索性分析结果，不能直接解释为因果关系，也不能替代疾控专业判断。Dashboard 中的风险等级应理解为课程实验中的量化提示，而不是正式公共卫生预警结论。

# 呼吸道传染病监测与早期预警可视化输入输出样例汇总

## 1. 输入样例

### 1.1 急性呼吸道哨点周报清洗数据

文件：

```text
data/processed/respiratory_weekly_clean.csv
```

字段示例：

```text
source_name,source_url,report_title,report_year,report_week,week_start,week_end,region_group,age_group,surveillance_scene,metric_type,pathogen_name,positive_rate,week_over_week_change,rank,ranked_pathogen,ili_percent,crawl_time,raw_file
```

用途：

```text
病原体阳性率趋势
最新病原体构成
门急诊与住院监测场景对比
```

### 1.2 流感监测周报清洗数据

文件：

```text
data/processed/influenza_weekly_clean.csv
```

字段示例：

```text
source_name,source_url,pdf_url,report_title,report_year,report_week,issue_no,week_start,week_end,region_group,metric_type,metric_name,metric_value,metric_percent,dominant_subtype,outbreak_count,crawl_time,raw_file,pdf_file
```

用途：

```text
ILI% 趋势
流感样病例暴发数趋势
2024 年流感分型比例和区域对比
```

### 1.3 聚类风险分组结果

文件：

```text
data/analysis/cluster_results.csv
```

字段示例：

```text
region,city,year_week,report_year,report_week,risk_level,risk_score,avg_temperature,avg_humidity,precipitation_total,wind_speed
```

用途：

```text
气象与风险散点图
省市风险分布图
风险 KPI
```

### 1.4 异常检测结果

文件：

```text
data/analysis/anomaly_detection_results.csv
```

字段示例：

```text
series_name,period,value,mean,stddev,z_score,anomaly_type
```

用途：

```text
异常检测表
预警候选列表
```

## 2. 中间输出样例

文件：

```text
data/dashboard-data.js
```

该文件由 `src/dashboard/prepare_dashboard_data.py` 自动生成，供前端页面读取。核心结构包括：

```text
meta
filters
trendRows
compositionRows
sceneRows
riskRows
correlations
anomalies
```

生成摘要：

```text
weeks: 2024-W01 至 2026-W20
pathogens: 11
cities: 31
trendRows: 1056
riskRows: 3844
```

## 3. 页面输出样例

页面入口：

```text
src/dashboard/dashboard.html
```

页面输出内容：

```text
KPI 指标卡
周度趋势折线图
最新病原体构成环图
监测场景对比柱状图
气象与风险散点图
省市风险分布图
强相关指标排名条
异常检测表
```

支持的交互：

```text
年份筛选
病原体筛选
监测场景筛选
省市筛选
趋势指标切换
周范围选择
趋势缩放
悬停提示
重置筛选
```

# 《呼吸道传染病监测与早期预警分析系统》数据清洗与预处理报告

## 一、清洗概况

本轮数据清洗与预处理基于采集阶段生成的 4 个结构化中间表完成。清洗流程采用“单表标准化、阶段性质检、时间粒度对齐、派生特征构建”的方式进行，最终形成 9 个清洗及派生产物，为后续数据分析和可视化提供统一数据基础。

| 阶段 | 输入表 | 输出表 | 输入记录数 | 输出记录数 | 去重数量 | 质检结论 |
|---|---|---|---:|---:|---:|---|
| 阶段1 | `chinacdc_monthly.csv` | `chinacdc_monthly_clean.csv` | 1,420 | 1,420 | 0 | 通过 |
| 阶段2 | `respiratory_weekly.csv` | `respiratory_weekly_clean.csv` | 3,576 | 3,576 | 0 | 通过 |
| 阶段3 | `influenza_weekly.csv` | `influenza_weekly_clean.csv` | 4,161 | 4,161 | 0 | 通过 |
| 阶段4 | `weather_daily.csv` | `weather_daily_clean.csv` | 95,139 | 95,139 | 0 | 通过 |
| 阶段5 | `weather_daily_clean.csv` | `weather_weekly.csv` | 95,139 | 13,609 | - | 通过 |
| 阶段6 | `weather_daily_clean.csv` | `weather_monthly.csv` | 95,139 | 3,131 | - | 通过 |
| 阶段7 | `weather_weekly.csv`、`respiratory_weekly_clean.csv`、`influenza_weekly_clean.csv` | `province_weekly_features.csv` | 13,609 + 3,576 + 4,161 | 13,609 | 不适用 | 通过 |

说明：阶段7不是从新的原始 CSV 读取数据，而是将阶段2、阶段3和阶段5的清洗结果按 `report_year`、`report_week` 进行周度特征合并。输出表仍以 `weather_weekly.csv` 的“城市 × 周”记录为主，因此输出记录数为 13,609。

清洗脚本路径为：

```text
src/cleaning/preprocess_data.py
```

运行命令为：

```bash
python src/cleaning/preprocess_data.py
```

## 二、阶段1：全国法定传染病月报清洗

### 1. 输入数据

- 输入文件：`data/interim/chinacdc_monthly.csv`
- 输出文件：`data/processed/chinacdc_monthly_clean.csv`
- 数据内容：全国法定传染病月度发病数和死亡数
- 原始记录数：1,420

### 2. 清洗处理

| 处理项 | 处理结果 |
|---|---|
| 年月字段 | 保留 `report_year`、`report_month`，新增 `period_month` |
| 病种名称 | 对新冠、流感等病种进行标准化 |
| 呼吸道病种标记 | 新增 `is_respiratory_focus` |
| 合计行标记 | 新增 `is_total_row` |
| 数值字段 | 将 `cases`、`deaths` 转换为整数格式 |
| 来源追溯 | 保留 `source_url`、`raw_file`、`crawl_time` |

### 3. 质量检查

| 检查项 | 结果 |
|---|---:|
| 输入记录数 | 1,420 |
| 输出记录数 | 1,420 |
| 删除重复记录 | 0 |
| 空发病数记录 | 0 |
| 空死亡数记录 | 0 |
| 空发病率记录 | 1,420 |
| 空死亡率记录 | 1,420 |

说明：本批次中国疾控月报主要提供发病数和死亡数，未提供发病率与死亡率，因此 `incidence_rate` 和 `mortality_rate` 保留为空字段，不影响基于病例数和死亡数的趋势分析。

## 三、阶段2：急性呼吸道传染病哨点周报清洗

### 1. 输入数据

- 输入文件：`data/interim/respiratory_weekly.csv`
- 输出文件：`data/processed/respiratory_weekly_clean.csv`
- 数据内容：全国急性呼吸道传染病哨点监测病原体阳性率、排名和分组信息
- 原始记录数：3,576

### 2. 清洗处理

| 处理项 | 处理结果 |
|---|---|
| 周次字段 | 保留 `report_year`、`report_week`，新增 `year_week` |
| 周起止日期 | 统一 `week_start`、`week_end` 格式 |
| 监测场景 | 保留门急诊流感样病例和住院严重急性呼吸道感染病例 |
| 病原体名称 | 对新型冠状病毒、流感病毒、呼吸道合胞病毒等名称进行标准化 |
| 阳性率字段 | 将 `positive_rate` 转换为可分析数值格式 |
| 排名字段 | 保留 `rank` 和 `ranked_pathogen` |

### 3. 质量检查

| 检查项 | 结果 |
|---|---:|
| 输入记录数 | 3,576 |
| 输出记录数 | 3,576 |
| 删除重复记录 | 0 |
| 空年龄组记录 | 1,896 |
| 空病原体名称记录 | 2,520 |
| 空阳性率记录 | 2,520 |
| 空排名记录 | 1,056 |
| 空排名病原体记录 | 1,056 |
| 空环比变化记录 | 2,520 |

说明：该表同时包含阳性率记录、地区主要病原体排名记录和年龄组主要病原体排名记录。不同指标类型适用的字段不同，因此部分字段为空属于结构性空值。例如排名类记录没有 `positive_rate`，阳性率类记录没有 `ranked_pathogen`。

## 四、阶段3：流感监测周报清洗

### 1. 输入数据

- 输入文件：`data/interim/influenza_weekly.csv`
- 输出文件：`data/processed/influenza_weekly_clean.csv`
- 数据内容：ILI%、实验室检测指标、优势流感亚型和暴发疫情数

### 2. 清洗处理

| 百分比指标 | 标准化 `metric_percent` |
| 普通数值指标 | 标准化 `metric_value` |
| 暴发疫情数 | 标准化 `outbreak_count` |
| 统一指标值 | 新增 `indicator_value`，便于统计和可视化 |

### 3. 质量检查

| 检查项 | 结果 |
|---|---:|
| 输入记录数 | 4,161 |
| 输出记录数 | 4,161 |
| 删除重复记录 | 0 |
| 空优势亚型记录 | 4,059 |
| 空统一指标值记录 | 56 |
| 空百分比指标记录 | 1,732 |
| 空普通数值指标记录 | 379 |

## 十、后续建议

1. 在数据分析阶段优先使用 `province_weekly_features.csv` 进行气象因素与呼吸道监测指标的相关性分析。
2. 对 `weather_daily_clean.csv` 中少量气象缺测值，可在建模阶段按城市和日期进行移动平均插补。
3. 对 `chinacdc_monthly_clean.csv` 中的重点病种，可进一步计算环比、同比和移动平均指标。
4. 对 `respiratory_weekly_clean.csv` 中的阳性率，可构建异常波动阈值，用于早期预警分析。
5. 对 `influenza_weekly_clean.csv` 中的优势毒株和暴发疫情数，可与 ILI% 联合分析流感活动强度。
6. 将清洗脚本、质量摘要、数据字典和运行截图纳入成员 B 的 Agent / Skill 加分材料。

# 数据清洗与预处理使用说明

本文档面向成员 B，用于说明如何运行数据清洗脚本，以及清洗后文件如何用于后续分析、可视化和报告撰写。

## 1. 输入数据

脚本默认读取 `data/interim/` 下的 4 个中间数据文件：

| 输入文件 | 内容 |
|---|---|
| `chinacdc_monthly.csv` | 中国疾控全国法定传染病月报数据 |
| `respiratory_weekly.csv` | 全国急性呼吸道传染病哨点周报数据 |
| `influenza_weekly.csv` | 中国流感监测周报数据 |
| `weather_daily.csv` | 31 个省会/首府城市日度气象数据 |

## 2. 运行方式

在项目目录 `呼吸道传染病监测与早期预警分析` 下执行：

```bash
python src/cleaning/preprocess_data.py
```

如需指定输入或输出目录，可使用：

```bash
python src/cleaning/preprocess_data.py --input-dir data/interim --output-dir data/processed
```

脚本只读取本地 CSV 文件，不会访问网络。

## 3. 主要清洗规则

脚本会自动完成以下处理：

- 去除重复记录。
- 统一空值表示，将 `-`、`--`、`—`、`NA`、`null` 等转换为空值。
- 清理字段前后空白和多余换行。
- 统一日期格式为 `YYYY-MM-DD`。
- 为周报数据生成 `year_week`、`week_start`、`week_end`。
- 为月报数据生成 `period_month`。
- 将病例数、死亡数、阳性率、气象指标等字段转换为可分析的数值格式。
- 标记呼吸道相关重点病种，例如新冠、流感、肺结核、百日咳、麻疹、猩红热、流行性腮腺炎。
- 标准化部分病种名和病原体名。
- 将日度气象数据聚合为周度和月度数据。
- 生成省份周度特征表，供后续趋势分析、预警分析和可视化使用。

## 4. 输出文件

脚本默认输出到 `data/processed/`：

| 输出文件 | 用途 |
|---|---|
| `chinacdc_monthly_clean.csv` | 清洗后的法定传染病月报表 |
| `respiratory_weekly_clean.csv` | 清洗后的急性呼吸道哨点周报表 |
| `influenza_weekly_clean.csv` | 清洗后的流感周报表 |
| `weather_daily_clean.csv` | 清洗后的日度气象表 |
| `weather_weekly.csv` | 周度气象聚合表 |
| `weather_monthly.csv` | 月度气象聚合表 |
| `province_weekly_features.csv` | 省份周度建模与可视化特征表 |
| `data_dictionary.csv` | 清洗产物字段说明 |
| `quality_summary.json` | 输入行数、输出行数、去重数量和缺失值统计 |

运行日志会追加到：

```text
logs/preprocess.log
```

## 5. 推荐后续分析顺序

1. 使用 `quality_summary.json` 检查各表行数、去重数量和缺失字段。
2. 使用 `chinacdc_monthly_clean.csv` 分析重点呼吸道病种的月度变化。
3. 使用 `respiratory_weekly_clean.csv` 分析主要病原体阳性率变化。
4. 使用 `influenza_weekly_clean.csv` 分析流感 ILI%、暴发疫情数和优势毒株变化。
5. 使用 `weather_weekly.csv` 或 `province_weekly_features.csv` 分析气象因素与呼吸道监测指标的关系。
6. 将 `province_weekly_features.csv` 交给成员 C，作为 Dashboard 的主要可视化数据源。

## 6. 报告中可写的清洗说明

本项目首先对 4 张采集中间表进行统一预处理，包括字段空白清理、缺失值标准化、日期格式统一、数值字段转换、重复记录删除和病种/病原体名称标准化。在时间粒度上，将日度气象数据聚合为周度和月度数据，使其可以分别与疾控周报和月报对齐。随后生成省份周度特征表，将气象变量与全国呼吸道病原体监测指标、流感监测指标进行组合，为后续趋势分析、相关性分析、聚类分析和早期预警分析提供统一数据基础。

## 7. 代码规范说明

为满足期末实验对代码规范性的要求，清洗脚本采用以下组织方式：

- 顶部模块注释说明脚本目标、输入输出和设计原则。
- 每个数据源对应一个独立的 `clean_*` 函数，便于定位和维护清洗规则。
- 通用工具函数统一处理文本清理、数值解析、日期解析、CSV 读写和去重。
- 主流程 `run_preprocess` 按“读取数据、单表清洗、聚合派生、质量输出”的顺序分段执行。
- 关键步骤均有中文注释，函数均提供 docstring，便于小组成员阅读和复用。
- 输出 `quality_summary.json` 和 `data_dictionary.csv`，便于人工审核和报告撰写。

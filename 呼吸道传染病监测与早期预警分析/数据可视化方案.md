# 呼吸道传染病监测与早期预警 Dashboard 可视化方案

## 1. 可视化目标

本模块由成员 C 负责，基于成员 A、成员 B 已完成的采集、清洗和分析结果，构建一个可交互的呼吸道传染病监测与早期预警 Dashboard。页面用于展示 2024-W01 至 2026-W20 的呼吸道病原体阳性率、ILI%、流感样病例暴发数、城市周度风险分级、气象与健康指标关系，以及异常检测预警候选。

Dashboard 的目标不是替代疾控专业判断，而是把多源公开监测数据整理成便于课堂展示、人工复核和后续扩展的可视化原型。

## 2. 输入数据

| 输入文件 | 数据内容 | 可视化用途 |
|---|---|---|
| `data/processed/respiratory_weekly_clean.csv` | 急性呼吸道哨点周报清洗数据 | 病原体阳性率趋势、病原体构成、监测场景对比 |
| `data/processed/influenza_weekly_clean.csv` | 流感监测周报清洗数据 | ILI%、流感样病例暴发数、流感分型比例 |
| `data/processed/province_weekly_features.csv` | 省市周度特征宽表 | 省市风险分布、气象与风险联动分析 |
| `data/analysis/cluster_results.csv` | 城市周度聚类风险分级结果 | 风险得分、风险等级、省市风险网格 |
| `data/analysis/correlation_matrix.csv` | 气象与健康指标相关性结果 | 强相关指标排名 |
| `data/analysis/anomaly_detection_results.csv` | Z-score 异常检测结果 | 异常检测表、预警候选列表 |

## 4. 图表设计

| 图表 | 类型 | 主要指标 | 作用 |
|---|---|---|---|
| 周度趋势图 | 折线图 | 病原体阳性率、ILI%、流感样病例暴发数 | 展示核心监测指标随周次变化的趋势 |
| 最新病原体构成图 | 环图 | 最新周不同病原体平均阳性率 | 展示当前优势病原体构成 |
| 监测场景对比图 | 柱状图 | 门急诊 ILI、住院 SARI、南北方 ILI 或流感阳性率 | 比较不同监测场景和区域口径 |
| 气象与风险散点图 | 散点图 | 平均气温、平均湿度、风险得分、风险等级 | 观察气象条件与风险得分之间的关系 |
| 省市风险分布图 | 类地图网格 | 省市平均风险得分、高风险周记录数 | 快速定位风险得分较高地区 |
| 强相关指标列表 | 排名条 | Pearson 相关系数 | 展示气象变量与健康监测变量之间的强相关关系 |
| 异常检测表 | 表格 | 序列、时期、数值、均值、z-score、异常类型 | 列出需要人工复核的预警候选 |

## 5. 交互功能设计

Dashboard 支持以下交互：

- 年份筛选：切换 2024、2025、2026 或全量数据。
- 病原体筛选：查看流感病毒、新冠病毒、呼吸道合胞病毒、肺炎支原体等不同病原体。
- 监测场景筛选：切换门急诊流感样病例、住院严重急性呼吸道感染等监测场景。
- 省市筛选：查看单个省市的风险得分和异常候选。
- 趋势指标切换：在病原体阳性率、ILI%、流感样病例暴发数之间切换。
- 周范围选择和趋势缩放：查看指定周次窗口。
- 悬停提示：在折线图、环图、柱状图、散点图和省市风险网格中查看详细数值。
- 重置筛选：恢复默认全局视图。

当筛选到 2024 年时，由于急性呼吸道病原体阳性率数据主要从 2025 年开始，页面会自动使用流感周报中的 ILI%、实验室阳性率、流感分型比例和暴发疫情数作为替代展示指标，避免图表空白。

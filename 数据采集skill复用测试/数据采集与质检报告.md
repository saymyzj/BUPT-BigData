# 数据采集与质检报告

## 1. 采集概况

本次使用 `bigdata-data-collection` 技能完成《医药上市公司研发投入与市场表现分析》的数据采集任务。采集对象为医药、生物科技、医疗器械、诊断和生命科学工具类上市公司，核心分析粒度为“公司 × 交易日”。

| 指标 | 结果 |
|---|---:|
| 初始公司池 | 45 家 |
| 有效行情公司 | 43 家 |
| 有效研发投入公司 | 42 家 |
| 行情记录数 | 10,836 行 |
| 研发投入记录数 | 527 行 |
| 合并核心记录数 | 10,836 行 |
| 原始 Yahoo JSON | 46 个 |
| 原始 SEC JSON | 43 个 |
| 来源 URL 侧写文件 | 89 个 |

## 2. 数据源说明

## 6. 失败 URL 和已知问题

`logs/failed_urls.json` 中记录了采集失败 URL：

| ticker | 数据源 | 现象 | 处理方式 |
|---|---|---|---|
| `SAGE` | Yahoo Finance Chart | 2024 日行情请求返回失败。 | 跳过该 ticker，不进入合并表。 |
| `BLUE` | Yahoo Finance Chart | 2024 日行情请求返回失败。 | 跳过该 ticker，不进入合并表。 |
| `HOLX` | SEC Company Tickers / Company Facts | 有 Yahoo 行情，但当前 SEC ticker 索引未匹配到 `HOLX` 对应 CIK。 | 保留行情记录，合并表中 252 行 `rd_expense_usd` 为空，并在报告中说明。 |

以上问题均来自公开数据源覆盖或接口返回状态，没有使用手工填补值，也没有生成伪造数据。

## 7. 反爬与合规措施

1. 采集公开 JSON 数据源，不采集登录数据、个人信息、病例详情或问诊记录。
2. 请求后保存原始 JSON 和来源 URL，保证结果可复现和可审计。
3. 低频串行请求，不进行高并发访问。
4. 失败 URL 写入日志，不进行无限重试。
5. 结构化数据中保留 `source_url`、`crawl_time`、`raw_file` 字段。

## 9. 后续建议

1. 后续分析可先剔除 `rd_expense_usd` 为空的 `HOLX` 记录，或补充人工核验后的 CIK 再重新采集。
2. 可扩展采集市值、收入、利润、总资产等 SEC 指标，进一步构造研发强度指标。
3. 可扩展到 2021-2025 多年日行情，进行跨年度市场反应分析。
4. 若课程要求中国 A 股医药上市公司，可将行情数据源替换为东方财富或交易所公开接口，保持当前框架不变。

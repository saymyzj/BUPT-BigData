# 数据可视化报告

## 页面概况

本次交付在 `数据可视化skill复用测试` 中构建了医药健康公司研发投入与市场风险 Dashboard。页面入口为 `src/dashboard/dashboard.html`，本地服务启动后访问：

```text
http://localhost:8765/src/dashboard/dashboard.html
```

## 数据范围

Dashboard 承接上一阶段 `数据分析skill复用测试` 产物，使用 43 家公司、10836 条 2024 年日行情记录，以及风险聚类、相关性矩阵、异常检测和关键词关注分析结果。时间范围为 2024-01 至 2024-12。

## 可视化结论

1. 2024 年月均调整收盘价在年中后整体走高，并在下半年出现回落。
2. 高关注公司数量为 15 家，主要来自聚类风险结果，不应直接解释为确定性投资风险。
3. 研发投入与波动率散点图用于识别高投入、高波动或高成交量公司，适合作为人工复核入口。
4. 相关性热力图显示变量之间的统计相关，不代表因果关系。
5. 异常候选表保留 z-score 绝对值较高的收益率记录，需结合公告、财报和市场事件进一步解释。

## 交互功能

页面实现股票选择、行业筛选、指标切换、日期范围选择、近 6 月/近 3 月缩放、重置筛选和悬停提示。筛选操作会同步影响趋势图、行业图、风险构成图、散点图和异常候选表。

# 输入输出样例汇总

## 输入样例

`company_2024_features.csv`

```text
ticker,company_name,industry_group,trade_year,trading_days,avg_close,year_end_adj_close,total_volume,...
ABBV,AbbVie Inc.,Pharmaceuticals,2024,252,177.2225,168.9247,1401514100,...
```

`anomaly_detection_results.csv`

```text
series_name,period,value,mean,stddev,z_score,anomaly_type
ABBV_return_pct,2024-04-04,-5.317791,0.067916,1.487563,-3.620491,low_value
```

## 中间输出

`data/dashboard-data.json` 包含：

```text
meta
inventory
monthly_trend
company_trend
industry_summary
companies
anomalies
correlations
keywords
```

## 页面输出

`src/dashboard/dashboard.html` 读取 `data/dashboard-data.json`，渲染 KPI、5 个 SVG 图表和异常表格。页面支持 URL 参数复现实验状态：

```text
?ticker=MRNA
?start=2024-07&end=2024-12
?window=3
?demoTip=1
```

# 数据可视化方案

## 1. 可视化目标

本次复用 `bigdata-data-visualization` skill，承接 `数据分析skill复用测试` 中的数据清洗与分析结果，构建可运行的交互式 Dashboard，用于展示医药健康上市公司的 2024 年市场表现、研发投入、风险聚类、相关性和异常候选。

## 2. 输入数据

| 输入文件 | 用途 | 状态 |
|---|---|---|
| `data/processed/stock_daily_clean.csv` | 月度趋势、股票筛选、收益率异常解释 | 可直接使用 |
| `data/processed/company_2024_features.csv` | 公司画像、行业对比、散点图 | 可直接使用 |
| `data/processed/rd_annual_clean.csv` | 研发投入历史背景 | 可直接使用 |
| `data/analysis/cluster_results.csv` | 风险等级、风险分数、聚类结果 | 可直接使用 |
| `data/analysis/correlation_matrix.csv` | 相关性热力图 | 可直接使用 |
| `data/analysis/anomaly_detection_results.csv` | 异常候选表 | 可直接使用 |
| `data/analysis/keyword_sentiment_analysis.csv` | 行业/关键词关注说明 | 可直接使用 |

## 3. 图表设计

| 图表 | 类型 | 指标 | 数据来源 |
|---|---|---|---|
| 月度趋势 | 折线图 | 月均调整收盘价、月均收益率、月成交量 | `stock_daily_clean.csv` |
| 行业对比 | 柱状图 | 行业平均研发投入、公司数、平均波动率 | `company_2024_features.csv` |
| 风险构成 | 环图 | 风险等级公司数占比 | `cluster_results.csv` |
| 研发投入与波动率 | 散点图 | 研发投入、波动率、成交量、风险等级 | `company_2024_features.csv` + `cluster_results.csv` |
| 相关性热力图 | 热力图 | Pearson 相关系数 | `correlation_matrix.csv` |
| 异常候选 | 表格 | 日期、收益率、z-score、异常类型 | `anomaly_detection_results.csv` |

## 4. 交互设计

Dashboard 支持股票选择、行业筛选、指标切换、起止月份选择、近 6 月/近 3 月缩放、重置筛选和图表悬停提示。折线图、行业图、环图、散点图和异常表会随筛选状态同步更新。

## 5. 页面结构

入口文件为 `src/dashboard/dashboard.html`，样式为 `src/dashboard/styles.css`，交互逻辑为 `src/dashboard/app.js`。前端数据由 `src/dashboard/prepare_dashboard_data.py` 生成到 `data/dashboard-data.json`。

## 6. 截图计划

截图保存在 `screenshots/visualization/`，包含首屏、股票筛选、日期范围、缩放窗口和悬停提示五类材料。
